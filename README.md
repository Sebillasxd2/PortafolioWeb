# Portfolio: Juan Sebastián Arduz Espada

Personal site, served by GitHub Pages at https://sebillasxd2.github.io/PortafolioWeb/ (English) and
https://sebillasxd2.github.io/PortafolioWeb/es/ (Spanish).

Static HTML and CSS, no build step, no JavaScript frameworks, no trackers. Every number on the page
comes from git history or an internal report; client names are omitted on purpose because the code
lives in private company repositories.

- `index.html`, `es/index.html`: the two language versions
- `assets/css/site.css`: the only stylesheet (light and dark via `prefers-color-scheme`)
- `assets/docs/`: the CV in English and Spanish (PDF)
- `assets/img/`: photo and icons

Rebuilt on 30 October 2026, replacing the 2025 template.
